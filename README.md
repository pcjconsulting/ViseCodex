ViseCodex describes a development environment running codex remotely in VS Code to create an agentic harnesses.
A local windows machine runs VS Code to remotely access VS Code running in an ubuntu VM in Azure.
This development environment uses the Codex VS Code extension, not the Codex cli.
The code produced by prompting Codex is not in this ViseCodex repo. That code remains local until it is vetted.
Instead, ViseCodex contains the information needed to create the Codex prompts.
