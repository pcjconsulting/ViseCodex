prompt
Create an agentic harness in python using the attached flowchart document.
The agent reads an oil and gas lease JIB (Joint Interest Billing) pdf file to create an excel csv.
This excel csv shall not allow macros.
This excel csv file shall contain (if present in the JIB) these fields:
• JIB line items
• Inventory and asset value adjustments
• Fixed monthly charges per active well for corporate administrative work
• Names and contact information
• Tax IDs
• Ownership percentages
The harness shall use the OpenAI Agents SDK.
The harness shall execute these steps:
Step 0
Retrieve the JIB pdf file from the user.
Step 1
Parse the JIB pdf file. Do this in two parallel stages:
    Stage 1a (text extraction): 
	• Read the JIB pdf file.
	• Parse JIB pdf text into a GLPayload object, GLPayload1.
    Stage 1b (vision extraction): 
	• Read the JIB pdf file.
	• Convert the JIB pdf file to an image (e.g., png, jpg) file, using pdf2image.
	• Parse the JIB image/OCR input into a GLPayload object, GLPayload2.
	• Use a frontier LLM model if needed to parse image/OCR.
Step 2
Compare GLPayload1 to GLPayload2 to verify the parsed fields agree.
Step 3
Scrape the Kansas Geological Survey (KGS) web site to determine the JIB lease is active.
KGS does not provide a formal API. All activity must be inferred from production recency.
Step 4
If all fields in GLPayload1 and GLPayload2 match, and the lease is active create the excel csv.
Otherwise, route to Human-In-The-Loop, and flag the discrepancies.

Design Choices
Validation is intentionally strict: malformed data or invalid numbers raise errors instead of silently passing.
The matching layer (Step 2) is deterministic and compares exact values rather than fuzzy tolerances.
Lease verification defaults to inactive when the external service does not respond clearly.
Manual review is favored any time a mismatch validation signal appears.
